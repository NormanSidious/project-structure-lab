# Архитектура проекта

Проект разделён на слои:
- `src/Calculator.App` — исходный код консольного приложения.
- `tests` — тесты логики.
- `docs` — документация.
- `assets` — статические ресурсы.

Такая структура позволяет отделить код от тестов и документации,
упрощает навигацию и соответствует общепринятым практикам C#-разработки.
