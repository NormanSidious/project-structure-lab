# Project Structure Lab (C# Console Calculator)

Учебный проект для демонстрации правильной структуры C#-репозитория.

project-structure-lab/
├── src/            # Исходный код (C#)
│   └── Calculator.App/
├── tests/          # Тесты
├── docs/           # Документация
├── assets/         # Ресурсы
├── Calculator.sln  # Решение
└── README.md

# Установка и запуск

Установите .NET SDK 8.0 (или Visual Studio 2022).

Перейдите в папку src/Calculator.App.

Выполните: dotnet run.

# Структура проекта

src/Calculator.App — консольное приложение.

tests — тесты.

docs — документация (см. architecture.md).

assets — ресурсы.
